# Portfolio website

Built with HTML, CSS and vanilla JavaScript only.

## Before you submit, edit these in index.html
1. Name (title, logo, hero, footer) if it is not yours.
2. `your-email@example.com` (contact section) -> your real email.
3. Project cards: replace the 2nd and 3rd with your real projects, and add a link only if it works.
4. About me text: rewrite in your own words.

## Deploy with GitHub Pages
1. Push this folder's contents to your GitHub repo (index.html at the root).
2. Repo Settings -> Pages -> Source: Deploy from a branch -> main / (root) -> Save.
3. After a minute your live URL is https://<username>.github.io/<repo-name>/
4. Submit that URL and the repo link in the Google Form.
